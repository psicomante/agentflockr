# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/psicomante/agentflockr/security/advisories/new)
on this repository.

Include what you found, the steps to reproduce it and the version
(`agentflockr --version`). I aim to reply within a week and to fix confirmed
problems in the next release.

## Scope

agentflockr runs on your machine, makes no network requests of its own and
reads the files and commands of your coding agents. Reports about how it
handles that data are in scope: for example, text from a session that reaches
your terminal, a command or the file system unsafely, or the permissions on
its index.

## Supported versions

Only the latest release gets fixes.
